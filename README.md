# ظلال الفجر — Dawnbound

لعبة منصات وألغاز سينمائية أصلية تعمل في المتصفح. لا تستخدم أي ملفات أو شخصيات أو ألغاز أو تصميمات من **LIMBO**؛ بل تقدّم عالماً ملوّناً مظلماً خاصاً بها، بعنوان **ظلال الفجر**.

## التشغيل

لا تحتاج اللعبة إلى تثبيت أو اتصال بالإنترنت:

1. افتح `index.html` في Chrome أو Edge أو Firefox حديث.
2. اضغط **بدء الرحلة** (هذه الضغطة تفعّل الصوت، كما تتطلبه سياسات المتصفح).
3. أو شغّل خادماً محلياً من مجلد المشروع:
   ```bash
   python -m http.server 8000
   ```
   ثم افتح `http://localhost:8000`.

## التحكم

| الإجراء | لوحة المفاتيح |
| --- | --- |
| المشي | `A` / `D` أو `←` / `→` |
| القفز / قفزة مزدوجة بعد اكتشافها | `W` أو `↑` أو `Space` |
| حمل صندوق / تدوير رافعة / تفعيل | `E` |
| إفلات الصندوق | `E` مرة ثانية |
| إيقاف مؤقت | `Esc` |
| كتم الصوت | زر الصوت في الواجهة |

يدعم المشروع أيضاً أزرار اللمس الظاهرة على الشاشات اللمسية.

## ما يتضمنه الإصدار

- حملة **25 فصلاً** في خمسة فصول قصصية، مصممة لمدة تقارب خمس ساعات عند الاستكشاف وحل الألغاز.
- نظام تقدم وحفظ تلقائي عبر `localStorage`، وخريطة فصول قابلة للاختيار.
- ألغاز مفاتيح وأبواب، صناديق وألواح ضغط، روافع وجسور، منصات متحركة، وتسلسلات **بلورات رنين** واضحة ومتصلة بالبوابة بصرياً.
- ست بيئات مرسومة برمجياً، مع طبقات parallax وضباب وطقس وكائنات مضيئة؛ دون صور أو مكتبات خارجية.
- رسوم شخصية متحركة وحركة/تصادم/قفز/حمل فعليين، ومؤثرات صوتية وموسيقى محيطية مولّدة عبر Web Audio API.
- واجهة عربية متجاوبة، خريطة، حوارات سياقية عند المراسي وعند حل العقد، وسجل بذور محفوظ.
- إعدادات إتاحة محلية: التلميحات، رحلة هادئة للمخاطر، حركة أقل، وتباين أعلى.

## فحص سريع للمشروع

```bash
node --check game.js
node tests/validate-project.cjs
```

الفحص لا يحتاج مكتبات خارجية؛ يتحقق من 25 فصلاً، ربط الواجهة، خيارات الإتاحة، وتحميل إطار Canvas واحد بمحاكاة محلية.

## ملفات المشروع

- `index.html` — البنية والواجهات.
- `styles.css` — التصميم المتجاوب.
- `game.js` — المحرك، المحتوى، الصوت، الحفظ والرسم.
- `GAME_DESIGN_AR.md` — وثيقة الحملة والألغاز وخطة خمس ساعات.
- `ART_DIRECTION_PROMPT_AR.md` — برومبت/دليل فني وصوتي مفصّل للإنتاج والتوسعة.

## ملاحظة إنتاجية

الحملة قابلة للعب من البداية إلى النهاية في المتصفح، وتُبنى فصولها من قوالب ألغاز محددة مع تنويعات مكانية وسردية لكل فصل. لرفعها من نموذج ويب مستقل إلى إصدار تجاري كبير، يمكن نقل البيانات إلى محرر مراحل وإضافة رسوم/موسيقى مرخّصة واختبارات لعب بشرية؛ وثيقتا التصميم والإخراج الفني تقدّمان مواصفة ذلك بوضوح.
